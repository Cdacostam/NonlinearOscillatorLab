# Data, inputs and recorded outputs

## Inputs and numerical results

- `inputs/closed_form_campaign.csv` gives the fixed trajectory inputs by case ID.
  Its decimal fields round-trip to the binary64 inputs. The cases marked `reference_check=1`
  were selected for the DOP853/Taylor reference comparison with seed 20261114.
- `results/v0.2.2_campaign/` contains the 1436-case closed-form campaign and the reference comparison.
- `results/v0.2.2_period/` contains period and trajectory benchmarks, both period-accuracy
  figure panels and the nine example periods.
- `results/v0.2.2_boundary/` contains the directed checks near a degenerate level and the
  large-barrier energy check.
- `results/v0.2.2_tests/` contains the installed-wheel Python test, category and coverage reports.
- `results/v0.2.2_independent/` contains the formula checks.
- `results/campaign_weierstrass.csv` records the Algorithm 1 campaign using the same five
  binary64 inputs in the same row order as the fixed trajectory input file.

The reproduction map in `../reproduce/README.md` identifies the command and recorded file for
each table and figure. Python scripts write generated results to `reproduce/outputs/` by
default. Wolfram `code_wl/MakeFigures.wls` writes to `figures/` and `tables/` at the
software archive root. The Python reference files read by the Wolfram scripts are in
`../benchmarks/` and `../examples/`. The Wolfram test and paclet-installation reports are
in `../code_wl/verification/`.

| Folder | Contents | Generation |
|---|---|---|
| `wolfram/` | Wolfram campaign of 200 problems, benchmark periods, period-accuracy data, environment and LaTeX numbers | `code_wl/MakeFigures.wls`, with `SeedRandom[20261019]` for the campaign |
| `results/` | Python period, trajectory, test, formula and Algorithm 1 results | Commands in `../reproduce/README.md` |
| `figures/` | Paper and supplement figures in PDF and PNG | Wolfram figure script, with Figure 3 / S5 generated by `reproduce/period_accuracy_figure.py` |
